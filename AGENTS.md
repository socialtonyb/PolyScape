# AGENTS.md

## Goal
Build this app end-to-end. Prefer simple, reliable choices.

## Working rules
- If you need to choose a tech stack, pick something common and beginner-friendly.
- Always make a runnable app (not just code snippets).
- After each change: run lint/tests if available, or add a basic test.
- Keep changes small and use pull requests.

## Definition of done (for any task)
- App runs locally with 2-3 commands.
- Clear README steps.
- Basic tests or smoke checks included.
